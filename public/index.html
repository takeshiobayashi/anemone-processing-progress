Key: NV = not verified · ? = count unknown · — = no value. Hover over headings for details.

Column guide
Run
Sequencing-run ID. A run may include samples unrelated to ANEMONE.
Set / Sets
Submission or sample-set IDs associated with the run, such as a DK code. These are not individual sampling events.
Groups
Three-letter groups from checked metadata. A code does not necessarily identify one sampling site.
Delivery
The selected delivery batch within a sample set; it may cover only part of that set.
Marker
The assay or marker being processed, for example MiFish.
Samp. / Ctrl.
Sample / control libraries in deliveries matched to metadata, counted separately per marker.
Done / C.done
Sample / control libraries with a processing result confirmed by a checked execution record. This confirms result coverage, not species-identification accuracy.
Miss. / C.miss
Expected sample / control libraries without a verified result after finalized processing. "?" means the count is unknown, not zero. These are not counts of missing species or raw FASTQ files.
State
Run or set view: the whole run or set. Sample breakdown: its sample libraries only. Delivery view: its job, samples and controls. A checked subset does not establish whole-run completion.
NV / RUN / OK / PART / FAIL
Not verified / running / all expected results verified / some results missing / job failed. These states require execution evidence; file presence alone does not certify success.
QC
Quality review of analysis results, verified separately.
DB
ANEMONE DB registration, verified separately.
Release
Scientific dataset release, verified separately from this progress page.
Notes
Source-consistency issues or documented ID corrections requiring attention.
No code
Sample-library names without a recognized group-code pattern. These libraries remain included through checked metadata.
