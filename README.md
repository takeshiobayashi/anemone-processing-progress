# ANEMONE processing progress

[View the public progress page](https://takeshiobayashi.github.io/anemone-processing-progress/)

This page helps collectors, data-generation participants and project managers
understand processing progress. Sequencing runs may contain no ANEMONE-related
samples. A run ID or processing status does not establish ANEMONE membership,
DB registration or public dataset availability. This is not a DB dataset catalogue.

This repository contains processing-status summaries and page assets only.
Descriptions, locality labels and personal/contact information are excluded.
Locality correspondence, analysis programs, private metadata, source workbooks
and research reports are maintained privately on cosmo.

The page distinguishes reported dates, file/data coverage and unverified results.
Publishing this page does not certify analysis quality or scientific-data release.
